# Практические задания к промежуточной аттестации

Источник: приложение № 7 файла [`source-materials/md/ФОС.md`](../source-materials/md/ФОС.md).

1. Контейнеризация ML-сервиса
   Дан проект с файлами `app.py`, `model.pkl` и `requirements.txt`. Разработайте Dockerfile, укажите команду сборки образа и запуска контейнера, а также способ передачи конфигурации без включения секретов в образ.

2. CI/CD pipeline
   Спроектируйте workflow, который при `push` выполняет линтинг, модульные тесты, тест загрузки модели, сборку Docker-образа и публикацию только при успешном прохождении проверок.

3. Версионирование данных и экспериментов
   Предложите последовательность действий и команд для фиксации версии датасета в DVC и регистрации эксперимента в MLflow так, чтобы другой разработчик мог воспроизвести результат.

4. Развертывание API
   Разработайте структуру FastAPI-приложения с endpoint `/predict`, Pydantic-схемой входных данных, обработкой ошибки валидации и endpoint `/health`.

5. Мониторинг
   Для сервиса бинарной классификации определите метрики Prometheus, которые позволят контролировать доступность, задержку, частоту ошибок, распределение предсказаний и признаки дрейфа.

6. Деградация модели
   После трех месяцев эксплуатации доля положительных предсказаний выросла с 20% до 45%, а целевая метрика стала доступна с задержкой две недели. Составьте план диагностики и безопасного реагирования.

7. A/B-тест
   Спроектируйте A/B-тест новой модели: распределение трафика, основная и защитные метрики, длительность, критерии остановки и способ отката.

8. Архитектура MLOps-решения
   Нарисуйте логическую схему системы, включающую репозиторий кода, хранилище данных, CI/CD, MLflow, DVC, Docker Registry, FastAPI-сервис, Prometheus и Grafana. Объясните потоки данных и артефактов.
