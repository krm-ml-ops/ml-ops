# Практические задания к зачету

Типовые практические задания к зачету включают:

1. Составить структуру репозитория для небольшого ML-проекта, включив каталоги для данных, кода, тестов, конфигураций, моделей и CI/CD.
2. Написать минимальный `Dockerfile` для FastAPI-сервиса, который устанавливает зависимости и запускает приложение через `uvicorn`.
3. Предложить набор шагов GitHub Actions для проверки качества кода, запуска тестов и сборки Docker-образа.
4. Описать, какие параметры, метрики и артефакты следует логировать в MLflow для задачи классификации.
5. Составить последовательность команд DVC для добавления датасета, фиксации метаданных в Git и восстановления результата на другой машине.
6. Разработать схему REST API для модели: endpoint, формат входных данных, формат ответа и обработка ошибок.
7. Определить набор продуктовых, модельных и инфраструктурных метрик для сервиса прогнозирования.
8. Предложить алгоритм действий при обнаружении `data drift` без немедленного падения целевой метрики.
9. Составить план A/B-теста новой версии модели и указать критерии остановки эксперимента.
10. Описать меры защиты логов и данных запросов, содержащих чувствительную информацию.
