# Practical Zachet Tasks

Typical practical tasks for the final zachet include:

1. Design a minimal repository structure for an ML project with code, data, tests, configs, and CI.
2. Write a basic `Dockerfile` for a FastAPI model service and explain runtime configuration.
3. Sketch a CI/CD workflow with tests, quality checks, and container build stages.
4. Define what must be logged to MLflow for a classification task.
5. Propose a DVC workflow for data versioning and metric comparison.
6. Design an inference API contract with request, response, and error handling.
7. Select monitoring metrics for a production ML service.
8. Propose a safe response plan to detected model drift.
9. Plan an A/B test for a new model version.
10. Explain how to protect logs and request data containing sensitive information.
