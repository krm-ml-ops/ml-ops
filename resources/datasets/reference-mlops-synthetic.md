# Reference MLOps Synthetic Dataset

`reference-mlops-project` генерирует учебный набор бинарной классификации командой:

```bash
python -m reference_mlops.generate_data --output data/synthetic.csv --samples 500 --seed 42
```

Источник данных не внешний: `sklearn.datasets.make_classification`. Поэтому набор воспроизводим при одинаковых `seed`, `samples` и версии scikit-learn. В репозитории CSV намеренно не хранится.

Столбцы `feature_0` ... `feature_3` имеют тип `float`; `target` имеет значения `0` или `1`. Признаки сгенерированы с двумя информативными признаками и двумя дополнительными, целевой столбец является классом. Это искусственные данные для демонстрации жизненного цикла MLOps, а не предметная модель и не данные для принятия решений.

Для проверки качества и обучения используются фиксированные `random_state=42` и стратифицированное разбиение 80/20. Параметры генерации и обучения находятся в `params.yaml` эталонного проекта.
