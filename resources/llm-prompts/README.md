# Prompts для учебной самопроверки

Эти prompts не заменяют проверку преподавателя и не являются источником итоговой оценки. Студент фиксирует существенные prompts и проверяет каждый полученный результат запуском, документацией или тестом.

## Ревью воспроизводимости

```text
Проверь этот README ML-проекта на скрытые ручные шаги. Верни список команд,
которые независимый проверяющий должен выполнить, и укажи отсутствующие версии,
данные, переменные окружения и ожидаемые артефакты. Не выдумывай содержимое файлов.
```

## Самопроверка защиты

```text
Составь пять коротких вопросов к моей реализации <инструмент/файл>.
Проверь понимание причины выбора, потока данных, отказа, безопасности и способа
воспроизведения. Не давай ответы, пока я не отвечу сам.
```

Правила допустимого использования ИИ приведены в [указаниях студентам](../../methodical-guidelines/students/README.md).
