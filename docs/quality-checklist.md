Статус отмечает текущее состояние опубликованных файлов относительно `source-materials/md/rpd/РПД-0.4.0.md` и `source-materials/md/fos/ФОС-0.4.0.md`.

- [x] В `docs/rpd.md` используется официальное наименование `ОСНОВЫ MLOps`.

- [x] `Exam/theoretical-questions.md` явно разделяет материалы приложения № 1 и приложения № 6 файла `source-materials/md/fos/ФОС-0.4.0.md`.

- [x] Структура `docs/rpd.md` упрощена для чтения в репозитории, но без изменения смысла содержательных разделов.

## Что проверять при следующих изменениях

- [ ] Любые новые изменения в `Exam/` сверять с конкретными приложениями `source-materials/md/fos/ФОС-0.4.0.md`.
- [ ] Любые новые изменения в `docs/rpd.md` сверять с формулировками `source-materials/md/rpd/РПД-0.4.0.md`.
- [ ] Не добавлять в содержательные файлы интерпретации, которых нет в исходных документах, без отдельного пояснения в `docs/source-alignment.md`.
