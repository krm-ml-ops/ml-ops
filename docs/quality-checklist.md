# Чек-лист согласования с исходными материалами

Статус отмечает текущее состояние опубликованных файлов относительно [`РПД-1.0.0.md`](../source-materials/md/rpd/РПД-1.0.0.md) и [`ФОС-1.0.0.md`](../source-materials/md/fos/ФОС-1.0.0.md).

## Выполнено

- [x] В `docs/rpd.md` используется официальное наименование `ОСНОВЫ MLOps`.
- [x] [`rpd.md`](rpd.md) основан на [`РПД-1.0.0.md`](../source-materials/md/rpd/РПД-1.0.0.md) и не подменяет содержание новыми repo-специфичными требованиями.
- [x] В `docs/rpd.md` сохранены содержательные разделы РПД, включая трудоемкость, тематический план, самостоятельную работу, ресурсы, условия реализации и рекомендации для ОВЗ.
- [x] В `docs/rpd.md` титульная и согласовательная часть не включена осознанно и вынесена в описание публикационной политики.
- [x] [`theoretical-questions.md`](../Exam/theoretical-questions.md) явно разделяет материалы приложения № 1 и приложения № 6 файла [`ФОС-1.0.0.md`](../source-materials/md/fos/ФОС-1.0.0.md).
- [x] `Exam/competence-tests.md` сохраняет структуру тестовых заданий с четырьмя вариантами ответа.
- [x] [`practical-tasks.md`](../Exam/practical-tasks.md) соответствует приложению № 7 файла [`ФОС-1.0.0.md`](../source-materials/md/fos/ФОС-1.0.0.md).
- [x] `Exam/grading.md` включает распределение баллов, правило допуска, порог прохождения и критерии оценивания.
- [x] [`README.md`](../Exam/README.md) явно сопоставляет опубликованные файлы с приложениями [`ФОС-1.0.0.md`](../source-materials/md/fos/ФОС-1.0.0.md).
- [x] `docs/README.md` и `docs/source-alignment.md` объясняют границы адаптации и источники.
- [x] `docs/measurement-model.md` содержит интерактивную таблицу с элементом, компетенцией, индикатором, уровнем, дескриптором, формой контроля, видом КИМ и ресурсом.
- [x] Модель охватывает текущий, рубежный, промежуточный и междисциплинарный контроль; каждый из пяти оставленных индикаторов имеет прямое подтверждение в опубликованных КИМ.

## Осознанные отличия от исходников

- [x] Титульные блоки, подписи, листы согласования и лист актуализации из [`РПД-1.0.0.md`](../source-materials/md/rpd/РПД-1.0.0.md) не публикуются в [`rpd.md`](rpd.md).
- [x] Структура `docs/rpd.md` упрощена для чтения в репозитории, но без изменения смысла содержательных разделов.
- [x] Материалы из [`ФОС-1.0.0.md`](../source-materials/md/fos/ФОС-1.0.0.md) распределены по нескольким файлам [`Exam/`](../Exam/), а не оставлены единым документом.

## Что проверять при следующих изменениях

- [ ] Любые новые изменения в [`Exam/`](../Exam/) сверять с конкретными приложениями [`ФОС-1.0.0.md`](../source-materials/md/fos/ФОС-1.0.0.md).
- [ ] Любые новые изменения в [`rpd.md`](rpd.md) сверять с формулировками [`РПД-1.0.0.md`](../source-materials/md/rpd/РПД-1.0.0.md).
- [ ] Не добавлять в содержательные файлы интерпретации, которых нет в исходных документах, без отдельного пояснения в `docs/source-alignment.md`.
