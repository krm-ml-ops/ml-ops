# Чек-лист согласования с исходными материалами

Статус отмечает текущее состояние опубликованных файлов относительно [`РПД-1.1.0.md`](../sources/rpd/md/РПД-1.1.0.md) и [`ФОС-1.1.0.md`](../sources/fos/md/ФОС-1.1.0.md).

## Выполнено

- [x] В `docs/rpd.md` используется официальное наименование `Основы MLOps`.
- [x] [`rpd.md`](rpd.md) основан на [`РПД-1.1.0.md`](../sources/rpd/md/РПД-1.1.0.md); сверка КРМ документирована в [`source-alignment.md`](source-alignment.md) и [`krm-alignment.md`](krm-alignment.md).
- [x] В `docs/rpd.md` сохранены содержательные разделы РПД, включая трудоемкость, тематический план, самостоятельную работу, ресурсы, условия реализации и рекомендации для ОВЗ.
- [x] В `docs/rpd.md` титульная и согласовательная часть не включена осознанно и вынесена в описание публикационной политики.
- [x] [`theoretical-questions.md`](../exam/theoretical-questions.md) явно разделяет материалы приложения № 1 и приложения № 6 файла [`ФОС-1.1.0.md`](../sources/fos/md/ФОС-1.1.0.md).
- [x] `exam/competence-tests.md` сохраняет структуру тестовых заданий с четырьмя вариантами ответа.
- [x] [`practical-tasks.md`](../exam/practical-tasks.md) соответствует приложению № 7 файла [`ФОС-1.1.0.md`](../sources/fos/md/ФОС-1.1.0.md).
- [x] `exam/grading.md` включает распределение баллов, правило допуска, порог прохождения и критерии оценивания.
- [x] [`README.md`](../exam/README.md) явно сопоставляет опубликованные файлы с приложениями [`ФОС-1.1.0.md`](../sources/fos/md/ФОС-1.1.0.md).
- [x] `docs/README.md` и `docs/source-alignment.md` объясняют границы адаптации и источники.
- [x] `docs/measurement-model.md` содержит интерактивную таблицу с элементом, компетенцией, индикатором, уровнем, дескриптором, формой контроля, видом КИМ и ресурсом.
- [x] Модель охватывает текущий, промежуточный и междисциплинарный контроль; каждый из семи оставленных индикаторов имеет прямое подтверждение в опубликованных КИМ.

## Осознанные отличия от исходников

- [x] Титульные блоки, подписи, листы согласования и лист актуализации из [`РПД-1.1.0.md`](../sources/rpd/md/РПД-1.1.0.md) не публикуются в [`rpd.md`](rpd.md).
- [x] Структура `docs/rpd.md` упрощена для чтения в репозитории, но без изменения смысла содержательных разделов.
- [x] В [`rpd.md`](rpd.md) добавлены таблица пререквизитов и два индикатора КРМ (ML-2.3 и LC-5.2); решение и источники зафиксированы в [`source-alignment.md`](source-alignment.md).
- [x] Дисциплина сохраняет четыре компетенции вместо целевого диапазона двух-трех; это осознанное исключение, а LC-3 оставлена с единственным индикатором LC-3.1, поскольку КРМ не содержит для нее другого индикатора.
- [x] Материалы из [`ФОС-1.1.0.md`](../sources/fos/md/ФОС-1.1.0.md) распределены по нескольким файлам [`exam/`](../exam/), а не оставлены единым документом.

## Что проверять при следующих изменениях

- [ ] Любые новые изменения в [`exam/`](../exam/) сверять с конкретными приложениями [`ФОС-1.1.0.md`](../sources/fos/md/ФОС-1.1.0.md).
- [ ] Любые новые изменения в [`rpd.md`](rpd.md) сверять с формулировками [`РПД-1.1.0.md`](../sources/rpd/md/РПД-1.1.0.md).
- [ ] Не добавлять в содержательные файлы интерпретации, которых нет в исходных документах, без отдельного пояснения в `docs/source-alignment.md`.
