# Сверка РПД и КРМ

Этот документ фиксирует полный набор элементов КРМ, используемых дисциплиной, и сверку результатов с КРМ. Рабочие документы курса используют результаты, подтверждаемые опубликованными КИМ. Источник всех цитат: [книга КРМ версии 3.0](../sources/krm/krm-v3.0.xlsx), лист `Профессиональные`; номер строки указан для независимой проверки. Уровень - уровень дескриптора из соответствующей колонки книги.
