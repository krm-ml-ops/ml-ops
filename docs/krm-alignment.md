# Сверка РПД и КРМ

Этот документ фиксирует сверку результатов с КРМ. Рабочие документы курса используют результаты, подтверждаемые опубликованными КИМ. Источник всех цитат: [книга КРМ версии 3.0](../sources/krm/krm-v3.0.xlsx), лист `Профессиональные`; номер строки указан для независимой проверки. Уровень - уровень дескриптора из соответствующей колонки книги. Полный перечень используемых элементов приведен в [выборке КРМ для дисциплины](../sources/krm-used/README.md).
