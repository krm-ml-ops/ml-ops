# Сверка РПД и КРМ

Этот документ фиксирует рабочее решение по измеримости результатов. `source-materials/` сохраняет историческую публикацию без изменений; рабочие документы курса используют только результаты, подтверждаемые опубликованными КИМ. Источник всех цитат: `data/krm-v3.0.xlsx`, лист `Профессиональные`; номер строки указан для независимой проверки. Уровень - уровень дескриптора из соответствующей колонки книги.

Подробная связь оставшихся результатов с КИМ приведена в [модели измерения](measurement-model.md). `docs/rpd.md`, [карта оценочных средств](../Exam/assessment-map.md), рубрики проекта и модель измерения используют только пять оставленных индикаторов. Любое повторное включение исключенного индикатора требует выполнения указанного условия.
