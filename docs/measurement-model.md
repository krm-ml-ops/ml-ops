# Модель измерения результатов обучения

Это интерактивная модель измерения ФОС: ссылки в строках ведут к заданию, КИМ, рубрике и ресурсу. Одна ЛР может подтверждать несколько индикаторов, поэтому строка таблицы описывает одну связь «ЛР - индикатор»; агрегированные строки рубежного, промежуточного и междисциплинарного контроля показывают совместное измерение нескольких индикаторов. Рабочий набор включает пять индикаторов. Полные правила баллов находятся в [рубриках ЛР](../modules/lab-rubrics.md) и [шкале](../exam/grading.md). Для ЛР и проекта действует [политика использования генеративного ИИ](ai-use-policy.md), на зачете ИИ запрещен.
