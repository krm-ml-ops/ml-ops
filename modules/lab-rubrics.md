# Рубрики лабораторных работ

Официальные критерии оценивания, минимальный порог, типовые ошибки и правила защиты опубликованы в тексте каждой лабораторной работы. Этот файл используется только для навигации; он не вводит самостоятельные критерии или шкалу баллов.

Каждая ЛР оценивается по официальной шкале `0-10` баллов; минимальный результат - `5/10`. Проверяемые доказательства обязательны для подтверждения результата: скриншоты не заменяют код, команды, журналы или артефакты. [Политика использования генеративного ИИ](../docs/ai-use-policy.md) применяется отдельно и не изменяет шкалу баллов.
