# Исходные материалы

## Структура

- [fos/](fos/) - фонды оценочных средств;
- [krm/](krm/) - исходная книга компетентностно-ролевой модели (КРМ);
- [krm-used/](krm-used/) - элементы КРМ, используемые в дисциплине;
- [labs/](labs/) - методические указания к лабораторным работам;
- [rpd/](rpd/) - рабочие программы дисциплины.

Каталоги [fos/](fos/), [labs/](labs/) и [rpd/](rpd/) содержат `docx/` с исходными документами и `md/` с их Markdown-версиями. [krm/](krm/) содержит исходную книгу, а [krm-used/](krm-used/) - выборку из неё для дисциплины.

`Markdown` версии документов `docx/` получены при помощи `pandoc`.

Остальные документы должны ссылаться на эти `Markdown` версии для удобства предпросмотра и навигации.

### Генерация `md`

```terminal
nix develop --command sh -c 'for source in sources/fos/docx/*.docx sources/labs/docx/*.docx sources/rpd/docx/*.docx; do target="$(dirname "$(dirname "$source")")/md/$(basename "${source%.docx}").md"; pandoc --from=docx --to=gfm --wrap=none --output="$target" "$source" || exit; done'
```

## Версионирование

Мы используем [SemVer](https://semver.org/lang/ru/) для обозначения версий документов.

Части репозитория могут быть основаны на не самой последней версии документов. Нам нужно обновлять репозиторий до последней версии. Поэтому мы храним и старую, и новую версию документов.
