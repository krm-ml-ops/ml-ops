## Структура и целеполагание ДПО

Главная цель - создание фонда оценочных средств (ФОС). Для этого необходимо соблюдать единый «канон» конструирования образовательных программ в сфере ИИ - работать с компетентностно-ролевой моделью (КРМ).

Программа дополнительного профессионального образования включает:

- особенности преподавания дисциплин в сфере ИИ в вузе в соответствии с требованиями индустрии и моделями компетенций;
- основы организации обучения ИИ во взаимодействии с индустриальными партнерами;
- современный инструментарий преподавателя в сфере ИИ;
- подходы и технологии реализации углубленного обучения в сфере ИИ;
- проектную командную работу: разработку РПД и комплексного ФОС по профильным ИИ-дисциплинам;
- обобщение и оценку результатов обучения, обмен опытом и итоговую аттестацию.

В рамках проектной работы необходимо:

1. Выбрать конкретную дисциплину.
2. Подготовить упрощенную документацию по ней - рабочую программу дисциплины (РПД).
3. Разработать и документировать комплексный ФОС.
4. Обобществить разработанные фонды оценочных средств между всеми участниками ДПО.

## Общие принципы проектной работы

Результаты ДПО должны использоваться для преподавания, организации НИР и практики студентов, а не оставаться формальными артефактами.

- Проект состоит из двух этапов: разработки проекта РПД и разработки ФОС.
- Группы по 5-7 человек формируются из преподавателей разных вузов, ведущих сходные дисциплины.
- Группа самостоятельно выбирает дисциплину, формы преподавания и содержание ФОС, оставаясь в поле КРМ.
- Каждой группе помогает куратор, не задающий обязательных решений.
- Предусмотрены промежуточные оценки и публичная защита перед экспертным бюро.
- Результат оформляется как цифровой артефакт в Git-репозитории.
- Цифровые артефакты обобществляются между всеми вузами-участниками ДПО.

## Этап 1: разработка РПД

Для РПД можно и нужно использовать задел, созданный в конкретных вузах. Полное соответствие требованиям ФГОС не является необходимым.

Рабочая программа дисциплины (РПД) - основной нормативный учебно-методический документ, определяющий содержание, объем, порядок изучения и результаты освоения конкретной учебной дисциплины в рамках образовательной программы.

Обязательные разделы РПД:

- цель и задачи дисциплины: чему и зачем учат;
- структура, содержание и результаты обучения дисциплины в логике КРМ, представленные таблицей;
- пререквизиты и связь с другими дисциплинами по КРМ: освоенные компетенции и индикаторы, с которыми обучающийся входит в программу;
- система оценки результатов обучения: краткое описание со ссылкой на развернутый ФОС, создаваемый на втором этапе.

РПД рассматривается не как самостоятельный продукт, а как техническое задание на разработку ФОС.

## Этап 2: разработка ФОС

ФОС не требуется оформлять отдельным стандартизованным документом: он представляется как наглядный и удобный Git-репозиторий.

Фонд оценочных средств (ФОС) - комплект методических и контрольно-измерительных материалов, предназначенных для оценивания уровня сформированности компетенций обучающихся и выпускников на соответствие требованиям КРМ. ФОС разрабатывается для конкретной дисциплины в соответствии с РПД.

ФОС включает:

- модель измерения уровня освоения компетенций в форме таблицы;
- готовые контрольно-измерительные материалы (КИМ);
- ресурсы для формирования и применения КИМ;
- методическое обеспечение процедур контроля и измерения уровня освоения;
- методическое обеспечение использования ресурсов.

### Принципы составления модели

1. Модель должна быть шире унитарной дисциплины РПД и включать междисциплинарные формы.
2. Следует предусмотреть вариативность форм контроля: например, коллоквиум или контрольную работу.
3. Связкой между РПД и КИМ служат дескрипторы освоения компетенций.
4. Модель должна быть полностью обеспечена ресурсами.
5. Нужно учитывать виртуозное использование ИИ студентами.
6. Модель должна быть интерактивной таблицей для удобной навигации по Git-репозиторию.

Формы контроля в рамках дисциплины:

- текущий контроль на каждом занятии или теме;
- рубежный контроль по модулям: контрольные работы, коллоквиумы;
- промежуточная аттестация: экзамены и зачеты.

Междисциплинарные формы:

- проектная работа и НИР студентов;
- практики;
- итоговая аттестация: дипломная работа.

## Виды КИМ

- Вопросы с выбором ответа и с открытым ответом с критериями.
- Темы для коллоквиумов с критериями.
- Темы рефератов, эссе и иных самостоятельных письменных работ с критериями.
- Темы для самостоятельного освоения и обсуждения на семинарах с критериями.
- Лабораторные работы с использованием компьютера.
- Задание на курсовую работу с критериями.
- Задания на научно-исследовательскую работу студентов с критериями.
- Задания на практику, как правило разработанные с индустриальным партнером, с критериями.
- Задание на квалификационную работу (диплом) с критериями.
- Билеты для экзаменов и зачетов.
- Иные формы заданий: деловые игры, ИИ-симуляторы и другие.

Количество и сочетание видов КИМ для конкретной РПД определяют разработчики ФОС.

## Ресурсы для составления КИМ

- Актуальная научная литература с аннотациями и метаданными: уровень готовности технологии решения, доступность кода, эксперименты на бенчмарках и другое.
- Массивы данных с метаданными, статистикой, описанием сбора, проверкой целостности и метрологией.
- Инструменты для работы с данными: вырезки, конвертеры, разметчики и другое.
- Бейзлайны и SOTA, например код для лабораторной работы.
- Бенчмарки с документацией и объяснением их роли в курсе.
- Шаблоны для обучения: написания кода и документов.
- Справочные и учебные материалы: тексты, видео, презентации; они также должны быть аннотированы и каталогизированы.
- Промпты для больших языковых моделей.

Ресурсы формируют сами разработчики ФОС из собственных материалов, материалов индустриальных партнеров и открытых источников.

## Методическое сопровождение

Необходимы методические указания:

- для обучающихся по работе с КИМ: например, руководство по лабораторной работе или НИРС;
- для преподавателей по организации оценивания и измерению результатов обучения, содержащие критерии оценивания;
- для преподавателей по использованию ресурсов при составлении КИМ.

Использование ресурсов преподавателями может быть ручным, автоматизированным с приложенным кодом или осуществляться с помощью промптов для ИИ.

Методические указания пишутся в свободной форме. Их ключевые свойства - удобство для других пользователей и отсутствие пробелов и ошибок.

## Оформление Git-репозитория

Git-репозиторий должен включать:

- общее описание содержания: что и зачем размещено;
- целевую РПД;
- интерактивную модель измерения уровня освоения компетенций;
- готовые КИМ, если они предусмотрены;
- ресурсы, включая вспомогательное программное обеспечение;
- методические указания для обучающихся и преподавателей.

На этапе разработки авторы выбирают публичную Git-систему или собственную систему вуза. Необходимо предоставить доступ организаторам ДПО.
