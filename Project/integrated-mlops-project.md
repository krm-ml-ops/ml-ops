# Эксплуатация ML-сервиса

## Задание

Для назначенного сценария подготовьте репозиторий, в котором можно воспроизвести обучение и эксплуатацию небольшой ML-модели. Используйте [reference-проект](../resources/reference-mlops-project/README.md) как стартовый ресурс, но замените не менее одного аспекта варианта: данные, признаки, модель, порог, API-контракт или правило наблюдаемости.

Представьте:

1. паспорт и версию данных;
2. команду воспроизводимого обучения, метрики baseline и сохраненную модель;
3. контейнеризированный API с проверкой входа и тестами;
4. CI-проверку либо локальный эквивалент с сохраненными логами;
5. одну прикладную и одну техническую метрику, dashboard и alert-правило;
6. схему архитектуры с потоками данных, артефактов и метрик;
7. защиту с запуском одной команды и объяснением собственного вклада.

Основной путь: Docker Compose и GitHub Actions или совместимый CI. При недоступности внешнего Git-хостинга допускается локальный скрипт CI с сохраненным логом; при невозможности запуска Docker допускается локальный Python-сервис и проверка конфигурации контейнера. Альтернатива не отменяет тесты, метрики и доказательство воспроизводимости.

Связь с КРМ и место формы в курсе указаны в [модели измерения](../docs/measurement-model.md).
